> R-03 Reviewer note: `refresh_reservation_id`의 authenticated envelope에 domain-separated actor binding을 포함하고 U1이 current capability와 직접 비교하도록 정의해, U2 repository 역호출 없이 actor mismatch를 거부할 수 있게 됐다.

> R-04 Reviewer note: U2 산출물은 C-01의 정확한 `refresh_delegated_capability_once` signature와 read 전용 port의 분리를 명시했지만, 이전 finding이 요구한 U1 provider design 자체의 signature 정렬은 전달된 현재 Unit 범위 안에서 확인할 수 없다. U1 provider와 U2 consumer가 같은 fixture를 사용한다는 선언만으로 기존 provider 계약 불일치가 해소됐다고 증명되지는 않는다.

> R-05 Reviewer note: Envelope claim, HMAC 형식, actor·attempt·generation·boot binding, signer/verifier 책임, boot 비교와 commit/registry race 처리까지 구체화되어 이전에 빠졌던 검증·restart 알고리즘이 정의됐다.

> R-06 Reviewer note: 현재 V1에는 lookup이 없음을 고정하고 ownership과 final retryable/terminal state를 한 no-I/O CAS로 기록한다. 중간 `started` state가 없어 CAS 전후 어느 crash에서도 고착이나 중복 lookup이 생기지 않는다.

> R-07 Reviewer note: NFR1.1과 NFR1.3은 SEC-U2-13, NFR3.7은 SEC-U2-12를 정확히 가리키도록 수정됐다.

### Summary

기존 reconciliation과 traceability 문제는 해결됐고 refresh envelope 자체도 구체화됐다. 그러나 그 envelope의 권위를 성립시키는 장기 안정 key primitive가 승인된 상위 계약에 없으므로, restart·rotation을 견디는 actor 검증을 구현할 수 있을 때까지 준비 완료로 볼 수 없다.
