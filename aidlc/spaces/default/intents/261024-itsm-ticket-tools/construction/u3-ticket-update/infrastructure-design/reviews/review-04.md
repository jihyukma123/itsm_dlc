> R-06 Reviewer note: Fixed base `89f48f9372635f443c719b7d64ca6900585bb112`, baseline digest, U3 manifest와 other-Unit manifest 분리는 추가됐고 helper 재실행은 2037/2284, 89.19%로 통과했다. 그러나 명령은 clean checkout을 검사하지 않고 helper도 base-to-working-tree diff와 untracked files를 포함한다. 현재 `HEAD`가 fixed base와 같은 commit인데도 미커밋·untracked U3 source에서 2284 executable lines를 측정해 통과하므로, evidence의 `tested HEAD`가 실제 검증 bytes를 식별하지 못한다. 이후 clean 상태를 만들기 위해 commit하면 HEAD가 바뀌지만 현재 결과는 그 commit에 결합되지 않는다. Coverage 전 `git status` clean을 강제하고 fixed base부터 tested HEAD까지 committed diff만 측정하거나, 검증 전후 source tree digest와 unchanged HEAD를 고정해 실제 테스트·coverage 대상 bytes를 동일 commit에 결합해야 한다.

> R-07 Reviewer note: `PIPE-U3-13`, ordered stage 11, Artifact Identity and Promotion Contract가 order 1~10 직후 한 번 만든 regular-file artifact의 `source_commit`, immutable packaging recipe ID와 locator, byte size, SHA-256을 atomic evidence로 봉인한다. Staging·production·rollback receipt는 locator bytes의 같은 digest를 재계산해야 하고 rebuild, mutable locator, digest mismatch는 명시적으로 차단된다. R-06의 tested-source binding은 별도 open issue지만 artifact 자체의 환경 간 identity와 receipt 계약은 구체화됐다.
