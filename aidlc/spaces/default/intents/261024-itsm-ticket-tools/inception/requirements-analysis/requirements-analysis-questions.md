# 요구사항 분석 질문

## Context

다음 사항은 승인된 상위 산출물과 ITSM API v2 계약에서 이미 확정되어 다시 묻지 않는다.

- 기존 Agent·Runner·서버 세션·사용자 위임 토큰·대화 이력·화면을 확장하고 새 Agent나 별도 서비스를 만들지 않는다.
- Agent에는 `ticket_read`, `ticket_write`, `ticket_update` 정확히 세 개의 function tool만 노출한다.
- 조회는 문서화된 전체 목록 필터·정렬·커서 페이지네이션과 ID 상세를 지원한다.
- 등록·수정은 최종 요약과 사용자의 명시적 확인 뒤에만 실행한다.
- 권한·가시성은 ITSM API가 판정하며, 비밀정보와 원본 내부 오류는 모델·도구 결과·로그·오류 응답에 노출하지 않는다.
- 등록은 동일 사용자·동일 요청에서 같은 멱등 상태를 유지하고, 수정은 `If-Match` 충돌 시 자동 덮어쓰지 않는다.
- 기존 동작의 회귀를 막고 실제 OpenAI API 호출 없는 자동화 테스트, 전체 회귀 테스트, 80% line coverage floor와 README 갱신을 완료한다.
