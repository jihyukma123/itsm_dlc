# 대화형 사용자 경험 질문

## Context

다음 사항은 승인된 상위 산출물에서 확정되어 다시 묻지 않는다.

- 새 화면, 화면 재설계, 새 Agent 또는 별도 서비스는 만들지 않는다.
- 사용자는 기존 ITSM Assistant 대화 화면에서 티켓 조회·등록·수정을 완료한다.
- 등록·수정 전에는 최종 변경 요약과 사용자의 명시적 확인이 필요하다.
- 권한과 티켓 가시성은 ITSM API가 판단하며, 비밀정보와 내부 오류 정보는 노출하지 않는다.
- 기존 사용자 전환, 세션, 대화 이력, 고정 모델 설정, 화면과 API 동작을 유지한다.
- 이 단계의 스케치는 새 시각 구성요소가 아니라 기존 대화 화면 안의 메시지 상태와 사용자 흐름을 다룬다.

- B. 기존 화면에 티켓 전용 빠른 실행 버튼만 추가한다
- C. 기존 화면에 티켓 전용 탭을 추가한다
- D. 별도의 티켓 작업 화면으로 이동한다
- E. 아직 정하지 않는다
- X. Other (please specify)

[Answer]: A — 기존 Assistant 대화 입력창에서 자연어로 요청하며 별도 메뉴·버튼·화면은 추가하지 않는다.

- D. 매 필드를 입력할 때마다 별도로 확인한다
- E. 아직 정하지 않는다
- X. Other (please specify)

[Answer]: A — 실행 직전 변경될 필드를 읽기 쉬운 요약으로 보여주고 확인·수정·취소 중 하나를 명확히 요청한다.
